# 도구 어댑터 — Pencil (`tool=pencil`)

`WIREFRAMES.md`(SSOT)를 Pencil `.pen` 파일로 그리는 절차. 다른 도구(추후 Figma)를 붙일 때는 이 파일과 같은 절 구성으로
`tool-<도구>.md`를 추가하고 SKILL.md의 `tool` 슬롯에 값을 더한다 — SSOT 문서 형식은 바꾸지 않는다.

## 1. 의존 도구

- MCP: `mcp__pencil__*` (`get_app_state` · `read_skill` · `get_style` · `execute`). Pencil 앱 또는 에디터 확장(Cursor·VS Code 등)이 등록하는 서버이며 devoks `setup-mcp`가 설치하지 않는다.
- `.pen` 파일은 암호화돼 있다 — **Read·Grep·Edit로 열지 않는다.** 읽기·쓰기는 전부 Pencil MCP로만 한다.
- Pencil MCP는 **에디터에 `.pen` 파일이 열려 있어야** 동작한다(열린 파일이 없으면 `A file needs to be open in the editor` 오류). 그래서 이 어댑터는 사용자가 에디터를 열어 둔 HITL 실행에서만 쓸 수 있다.

## 2. 사전 조건 확인 (그리기 전 1회)

1. `mcp__pencil__*` 도구가 세션에 없으면 → 그리지 않는다. 보고에 "Pencil MCP 미등록 — Pencil 앱/에디터 확장 설치 후 재실행"을 남긴다.
2. `get_app_state` 호출. "file needs to be open" 오류면 → HITL: 파일 열기 요청은 범위 확인 메시지(SKILL §1)에 이미 들어 있다. 그래도 열려 있지 않으면 `<out>/design/wireframes.pen`을 열어 달라고 **한 번만** 다시 알리고 기다린다 — 그 뒤에도 안 되면 문서만 완성하고 미작도로 보고한다. 비-HITL: 그리지 않고 보고에 남긴다.
3. 열린 파일 경로가 frontmatter `design_file`과 다르면 어느 파일에 그릴지 확인한다(HITL) — 다른 문서의 `.pen`에 덮어쓰는 사고를 막는다.

## 3. 그리기

1. **`read_skill()`로 Pencil 공식 가이드를 먼저 읽는다** — `.pen` 스키마와 `execute` 사용법의 SSOT는 Pencil 쪽이며 버전에 따라 바뀐다. 이 파일에 API를 옮겨 적지 않는 이유다. 가이드가 가리키는 하위 문서(예: 웹앱·모바일 가이드)는 대상 플랫폼에 맞는 것만 읽는다.
2. 스타일: lo-fi 회색조. `get_style`에 와이어프레임·저충실도 계열 스타일이 있으면 그것을 쓰고, 없으면 회색조·시스템 폰트로 직접 지정한다. 브랜드 색·폰트를 넣지 않는다(DESIGN.md 몫).
3. 프레임: §2 인벤토리의 W-n마다 프레임 1개, 이름은 프레임 열과 **정확히 같게**(`W-1 <화면>`). 크기는 §1 기준 뷰포트. 상태 프레임 범위는 가이드 §4(기본 상태는 전 화면, 그 밖의 상태는 핵심 흐름 화면만), 이름은 `W-n <화면> / <상태>`.
4. 배치: 프레임을 §3 흐름 순서로 왼쪽→오른쪽에 놓아 캔버스만 봐도 흐름이 읽히게 한다.
5. 내용: §4 우선순위 블록 순서·핵심 문구 그대로. 이미지·아이콘은 회색 박스와 라벨로 대신한다.
6. `execute`가 실패하면 도구 설명대로 `editId` + `edits`로 고쳐 재시도한다(스니펫 전체 재전송 금지).

## 4. 대조·검증

1. 그린 뒤 `execute`로 문서의 프레임 이름 목록을 읽어 §2 프레임 열과 1:1 대조한다 — 누락·여분·이름 불일치를 고친다.
2. §4 "검증할 제약"을 프레임 기준으로 판정해 §6에 남긴다(예: 기준 뷰포트 높이 안에 블록 1~3이 들어가는가).
3. 대조 결과(프레임 수·불일치 0건)를 보고에 한 줄로 남긴다.

## 5. 하지 않는 것

- hi-fi 시안, 디자인 토큰·변수 정의, 컴포넌트 라이브러리 구축 — 디자인 시스템 B-n 몫이다.
- `.pen`을 SSOT로 취급해 문서를 역으로 고치는 것. 캔버스에서 사용자가 직접 바꾼 내용이 있으면 변경점을 보고하고 **문서에 먼저 반영**한 뒤 맞춘다.
