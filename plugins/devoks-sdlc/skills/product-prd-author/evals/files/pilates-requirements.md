# 필라테스 센터 예약 앱 요구사항 메모 (대표 미팅 정리)

- 대상: 강사 2~5명 규모 소형 필라테스 센터. 지금은 원장이 카카오톡 + 엑셀로 예약을 받는다.
- 원장 불만: 하루 평균 30건 넘는 예약/변경 문의를 카톡으로 응대, 엑셀 반영 누락으로 더블부킹이 월 4~5건 생김.
- 회원 앱은 하단 탭 3개(예약 / 내 수업 / 마이)로 구성하고 Firebase로 푸시 보내기.
- 예약은 빠르고 간편하게. 원장용 관리자 대시보드 필요.
- 회원권(10회권 등) 잔여 횟수 자동 차감.
- 노쇼가 많으니 알림 보내면 노쇼가 줄어들 것.
- 결제는 일단 현장 결제 유지, 온라인 결제는 나중에.
- 개발자 1명 + 디자이너 0.5명, 3개월 안에 첫 버전 출시가 목표.
- iOS/Android 모두. 회원 개인정보(연락처, 건강 특이사항) 다룸.
- 경쟁: 대형 예약 SaaS가 있지만 월 구독료가 비싸고 기능이 너무 많다는 원장 의견.
