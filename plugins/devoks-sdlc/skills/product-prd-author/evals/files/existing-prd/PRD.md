# 팀 회고 보드 — Product Requirements Document

> **개요:** 5~15명 개발팀이 스프린트 회고를 30분 안에 끝내고 액션 아이템을 다음 스프린트까지 추적하도록 돕는 웹 도구.

## 1. 문제 정의
- **문제 진술:** 개발팀 리드가 / 격주 회고에서 / 의견을 모아 액션을 정하려다 / 의견 수집과 정리가 수작업이라 / 회고가 60분을 넘기고 액션 아이템의 70%가 잊힌다
- **JTBD:** 회고할 때, 나는 의견을 빠르게 모아 액션으로 바꾸고 싶다, 그래서 다음 스프린트에 실제로 개선되도록.
- **Why now:** 원격 근무 전환으로 화이트보드 회고 불가
- **근거:** 사내 리드 6명 인터뷰 (sources/kickoff-notes.md)

## 2. 타깃 사용자
| 구분 | 사용자 | 현재 해결 방식 | 근거 |
|---|---|---|---|
| 주 타깃 | 개발팀 리드(회고 진행자) | 구글 문서 + 수동 정리 | 인터뷰 |
| 얼리어답터 | 플랫폼팀 리드 | | |
| **제외** | 비개발 조직 — 회고 형식이 달라 MVP 검증 대상 아님 | | |

## 3. 가치 제안 & 대안
- **핵심 가치 (한 문장):** 의견 수집부터 액션 추적까지 한 곳에서, 회고 30분.
| 대안 | 사용자가 겪는 한계 | 우리의 차이 |
|---|---|---|
| 아무것도 안 함 | 액션 망각 | 액션 추적 |
| 구글 문서 | 정리 수작업 | 자동 그룹핑·투표 |
- **수익화 지점:** MVP 범위 아님 (사내 도구)

## 4. 목표 & 성공 지표
| ID | 목표 (≤3) |
|---|---|
| G-1 | 회고 소요 시간 단축 |
| G-2 | 액션 아이템 실행률 향상 |

| 지표 | 연결 목표 | 기준값(현재) | 목표치 | 측정 방법 | 기한 |
|---|---|---|---|---|---|
| **핵심 KPI** 액션 아이템 완료율 | G-2 | 30% | 60% | 다음 회고 시점 완료 체크 비율 | 2026-12 |
| 보조: 회고 소요 시간 | G-1 | 65분 | 30분 | 세션 시작~종료 시간 | 2026-12 |
| 가드레일 | — | | 참여율 80% 이하로 떨어지지 않음 | 세션 참여자/팀원 | |

- **중단·재검토 기준:** 3개 팀 도입 후 2회 회고 연속 완료율 40% 미만이면 재검토

## 5. 핵심 시나리오
- **S-1 회고 진행:** 리드가 세션을 열면 팀원들이 익명으로 카드를 쓰고, 비슷한 카드가 묶이고, 투표로 상위 3개를 골라 액션을 정한다.
- **S-2 액션 추적:** 다음 회고 시작 시 지난 액션의 완료 여부를 먼저 확인한다.
