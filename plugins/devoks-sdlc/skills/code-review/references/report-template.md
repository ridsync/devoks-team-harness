# report-template — 코드리뷰 리포트 템플릿 (출력 SSOT)

`code-reviewer` 에이전트가 최종 메시지로 리턴하는 리포트의 형식이다.

**템플릿에 포함된 이모지(📋 🧭 ✅ ⚠️ ❌ 🔍 🔴 🟠 🟡 🔵 📊 🚀)를 반드시 그대로 포함하여 출력한다.**
심각도 분류 및 이슈 형식은 `.claude/refs/code-review.md §8`을 따른다.
이슈 번호는 심각도 그룹을 가로질러 **통번호**로 매긴다(1, 2, 3, … — 그룹마다 1부터 다시 세지 않는다). 사용자가 "1, 3번 고쳐줘"처럼 번호로 지시할 수 있게 하기 위해서다.
