## F-1 빈 회의실 찾기

**FRD 시드** — 이 블록을 그대로 `/devoks-sdlc:feature-frd-author frd=<본문>`에 넘긴다.

- 기능: 직원이 지정한 시간대(지금 포함)에 비어 있는 회의실을 확인하고, 조건으로 좁히거나 특정 회의실의 하루 예약 현황을 볼 수 있다.
- 대상 사용자: 회의실을 직접 잡아야 하는 사내 직원 (PRD §2 주 타깃)
- Why: G-1 — 메신저에 묻지 않고 빈 회의실을 스스로 확인하게 하는 것이 제품의 출발점(S-1, S-2). 현황이 한 곳에 있다는 가설(A-1)을 직접 검증한다.
- Success: 기여 지표 — 조회→예약 전환율(보조), 메신저 회의실 문의 건수(보조). 남겨야 할 계측 — 조회 이벤트(조건·시각·사용자) → FR-8 / NFR-5. 현황 반영 지연 → NFR-3.
- Non-goals: 예약 확정·변경·취소(F-2 몫), 회의실 외 공간 조회, 실제 점유 자동 감지
- 관련 제약·NFR: NFR-2, NFR-3, NFR-4, 플랫폼 제약(PRD §7)
- 열린 질문: Q-1, Q-2, Q-6, Q-7, Q-8
- 출처: PRD v0.1.0 FR-1, FR-2, FR-3

## F-2 즉시 예약 · 내 예약 관리

**FRD 시드** — 이 블록을 그대로 `/devoks-sdlc:feature-frd-author frd=<본문>`에 넘긴다.

- 기능: 직원이 찾은 빈 회의실을 별도 승인 없이 즉시 예약하고, 자신의 예약을 확인·변경·취소할 수 있다. 취소된 시간대는 다른 직원에게 다시 빈 시간으로 보인다.
- 대상 사용자: 회의실을 직접 잡아야 하는 사내 직원 (PRD §2 주 타깃)
- Why: G-2 — 찾은 자리에서 회의실 확보까지 끝내야 메신저 문의를 대체한다(S-1). G-3 — 취소가 현황에 반영돼야 정보를 믿고 쓴다(S-2).
- Success: 기여 지표 — 주간 서비스 경유 예약 건수(핵심 KPI), 조회→예약 전환율. 남겨야 할 계측 — 예약 생성·변경·취소 이벤트 → FR-8 / NFR-5. 제품 불변식 — 이중 예약 0건 → NFR-1.
- Non-goals: 반복(정기) 회의 예약, 회의실 장비 예약, 외부인 예약, 미사용 예약 자동 해제(F-5 몫)
- 관련 제약·NFR: NFR-1, NFR-2, NFR-3, NFR-4
- 열린 질문: Q-1, Q-4, Q-5, Q-7, Q-8
- 출처: PRD v0.1.0 FR-4, FR-5

## F-3 회의실 정보 관리

**FRD 시드** — 이 블록을 그대로 `/devoks-sdlc:feature-frd-author frd=<본문>`에 넘긴다.

- 기능: 회의실 정보 담당자가 회의실의 위치·층·수용 인원·사용 가능 여부를 등록·수정하고, 쓸 수 없는 회의실을 사용 중지할 수 있다.
- 대상 사용자: 회의실 정보 관리 담당자 (PRD §2 보조 — 주체 미확정)
- Why: G-1, G-3 — 회의실 목록이 정확해야 조회 결과가 의미 있고, 쓸 수 없는 회의실이 예약되지 않는다(S-3). A-4(관리 주체 존재) 검증 대상.
- Success: 기여 지표 — 직접 기여 지표 없음(F-1·F-2 지표의 전제). 남겨야 할 계측 — 없음 (필요 시 FRD에서 판단).
- Non-goals: 회의실 장비 관리, 부서별 사용량 정산, 직원 계정 관리
- 관련 제약·NFR: NFR-3, NFR-4
- 열린 질문: Q-1, Q-2, Q-10
- 출처: PRD v0.1.0 FR-7

## F-4 이용 기록 (지표 계측)

**FRD 시드** — 이 블록을 그대로 `/devoks-sdlc:feature-frd-author frd=<본문>`에 넘긴다.

- 기능: 시스템이 빈 회의실 조회와 예약 생성·변경·취소를 시각·사용자·회의실·대상 시간대와 함께 기록해, 출시 후 제품 지표를 측정할 수 있게 한다.
- 대상 사용자: 제품 지표를 보는 서비스 운영자 (직원에게 보이는 기능 아님)
- Why: PRD §4 — 지표 데이터를 개발 중에 남기지 않으면 출시 후 G-1·G-2 달성 여부를 측정할 수 없다.
- Success: 기여 지표 — 핵심 KPI(주간 서비스 경유 예약 건수), 조회→예약 전환율의 데이터 원천. 남겨야 할 계측 — FR-8 자체, 보존 NFR-5.
- Non-goals: 지표 대시보드·리포트 화면, 메신저 문의 건수 수집(제품 밖 데이터, Q-3)
- 관련 제약·NFR: NFR-4, NFR-5
- 열린 질문: Q-3, Q-8
- 출처: PRD v0.1.0 FR-8

## F-5 미사용 예약 자동 해제

**FRD 시드** — 이 블록을 그대로 `/devoks-sdlc:feature-frd-author frd=<본문>`에 넘긴다.

- 기능: 시스템이 예약 시작 후 일정 시간 안에 사용이 확인되지 않은 예약을 해제해, 그 회의실을 다시 빈 회의실로 돌린다.
- 대상 사용자: 회의실을 직접 잡아야 하는 사내 직원 (해제로 생긴 빈 회의실을 쓰는 쪽)
- Why: G-3 — 예약만 걸어 두고 쓰지 않는 회의실이 "빈 회의실" 정보를 왜곡한다는 가정(A-3) 대응. MVP 운영 중 A-3이 확인될 때 착수.
- Success: 기여 지표 — 가드레일 "예약 후 미사용 비율". 남겨야 할 계측 — 사용 확인·자동 해제 이벤트 (판정 방법 Q-11 확정 후 FRD에서 정의).
- Non-goals: 센서 등 실제 점유 자동 감지, 반복 미사용자 제재
- 관련 제약·NFR: NFR-1, NFR-3
- 열린 질문: Q-11
- 출처: PRD v0.1.0 FR-6
